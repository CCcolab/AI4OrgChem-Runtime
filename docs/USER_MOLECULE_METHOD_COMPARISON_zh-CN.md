# 用户分子入口：已有方法对照与解释边界

日期：2026-10-05；DRAFT-3。状态：公开资料静态核查完成；方法等价性 NOT_ESTABLISHED，外部对照计算 NOT_EXECUTED。以下比较用于 A01 审阅，不表示本项目已实现 BLW、ALMO、NBO、cDFT 或 SAPT 服务。

## 1. 为什么保留当前条件定义

本项目现有特色是把登记 h/S/F 与十五类 ERI 条件规则变成可检查、可复算、可追溯的服务。保留该定义的直接理由是明确复现已冻结协议与实现；尚无依据宣称其优于其他局域化方法或普遍适用于用户分子。

选择服务前，用户应看到条件态摘要、自己的分片、比较量与允许解释。方法维护者另审 [操作性定义](USER_MOLECULE_CONDITION_DEFINITION_zh-CN.md)、本表和独立参考。无法建立适用依据的研究问题保持 NOT_REVIEWED；已知范围外拒绝。

## 2. 方法对应关系

“自洽”指各方法自身定义下的迭代/优化，不表示方程相同。表中外部方法按所查版本/模式说明；不能覆盖其全部变体。

| 方法 / 依据 | 基底、片段与占据 | 限制/修改对象及求解 | 能量与本项目的关系 |
|---|---|---|---|
| 本项目冻结条件核 | 原分子球谐 AO；按 z 奇偶分类；碳 A/B 为 π AO 组；全体系 RKS 占据，无显式固定组电子数 | 屏蔽跨组 π h/S/F，删除十五类 ERI；原 AO semilocal XC；屏蔽 S 下迭代 | 报告指定功能式固定点能量及 Eord−Econd；变分关系未建立，不能自动称 BLW/ALMO/共轭能 |
| BLW-DFT [M1] | 电子及原始轨道空间划块；块内轨道展开受限；块间轨道可非正交；块占据是态定义的一部分 | 自洽构造块局域态；限制允许轨道空间，不能等同于本项目修改 S 和 ERI | 研究局域参照与离域效应；须先对齐态、几何、占据和能量定义；论文所述 GAMESS 实现不证明本机或标准发行版已具备 |
| ALMO-EDA [M2] | 由片段轨道和准备态建立参照；局域松弛后再释放跨片段混合；代际/子空间定义需登记 | 冻结、极化与电荷转移分步骤；受限轨道优化，未使用本项目十五类 AO 积分删除 | 各分量依赖准备态和局域空间；不能把本项目单个差值直接命名为 CT/POL |
| 共价 ALMO-EDA [M3] | 所查模式从两个双重态自由基片段及自旋耦合出发；需电子/几何准备 | 为共价键重新定义准备、冻结及松弛步骤；所查手册限定单键分析 | 共价分片不能照搬非共价 EDA；不自动适用于任意两组碳或切断共轭结构 |
| NBO $DEL [M4] | NBO 表示；按轨道或供体—受体 Fock 元素选择删除，不是 xy 奇偶 AO 组 | 所查教程由删除后的 NBO Fock 构造密度并用 one-pass SCF evaluator 求能；不能概括为与本项目相同的完整条件 SCF | 教程区分 LEWIS 情形与其他删除的变分一致性；这是审查问题参照，不是本项目存在相同问题的证据 |
| cDFT / PySCF 示例 [M5] | 选择布居定义、轨道/原子/功能组及目标值；不同权重定义不同问题 | 用拉格朗日乘子/约束势控制布居，迭代满足约束；不自动删除 h/S/F 和十五类 ERI | 布居约束态能量与当前条件功能式不同；可比较约束、占据和解释，不能作等价实现 expected |
| SAPT / F/I-SAPT [M6] | 非共价相互作用/官能团分解；分子内方案另有链接体与电子对分配 | 基于 SAPT 分项；所查 F/I-SAPT 使用 density-fitted SAPT0，不是本项目条件 RKS | F-SAPT 官方不鼓励切断双键、三键、芳香结构；合法分片与方法范围未确认时不作为标准答案 |

NBO 的提醒促使本项目明确能量、密度和算子对应关系；本项目的关系只能由自己的允许变化定义、独立核查与范围审阅判断。没有证明时记录 NOT_ESTABLISHED，不把“未证明”写成“已证明错误”。

## 3. A01 审阅必须留下的判断

1. 研究问题和为什么选择当前条件操作；它与外部方法分别改变了什么。
2. 两组 π AO 与物理分子片段、局域轨道块、片段电子数之间的区别；当前没有的约束不能补写。
3. 同几何 Eord−Econd 的符号和参考能量；若对照采用相反符号或片段准备能，显式说明。
4. 允许变化、占据/简并与能量—算子关系；范围审阅批准的解释和禁止外推。
5. 采用哪些外部方法作解释对照，哪些因不适用而不采用；缺少程序、坐标或定义时写具体未知。

同数学定义的独立参考用于代码验证；不同方法的结果用于科学解释对照。两条证据路径见 [参考合同](USER_MOLECULE_CONDITION_DEFINITION_zh-CN.md)，不能互相替代。
