# 条件 SCF 求解器修订候选 v2

2026-10-05。独立增补，验收前状态为 ENGINEERING_CANDIDATE / NUMERICAL_NOT_EXECUTED。这不是科学方法批准或生产 Compute 开放。此前 `8fc64a4` 交付和 `65c5848` 数值失败记录保留。

## 修订内容与不变量

冻结科学提交及其 `_evaluate_density`、h/S/F 投影、十五类 ERI、原 AO/grid XC、几何/原子顺序和全局闭壳层 2/0 占据均不改变。普通态/profile/比较容差保持原字节。新的生产候选在 runtime 中另行实现迭代控制；独立参考在 reference 中另行实现，不调用生产算子或停止辅助函数。

传统 ΔD/ΔE 小步只触发候选停止检查。在候选 D 上重算真实 F/E，检查原最终对易子、电子数、幂等、账本闭合与屏蔽，并用真实 F 和 S̃ 的全局 Aufbau 密度检查映射残差 ≤2e-8。候选/当前能量差也须 ≤1e-9 Eh；最终重算再次检查。原最终谱 gap 工程门槛 1e-6 Eh 保留，小 gap/未定义不提供可比端态资格。

候选平台停滞但真实检查失败时清空各自 DIIS 历史，随后两周期使用真实 F，再恢复原 DIIS。最多 100 周期、每求解至多 201 次功能式求值；不自动增加周期或重试。最终真实谱是诊断，未合格返回密度不会用该谱的映射密度替换。末次迭代谱另存。

PySCF 提供 DIIS 等成熟求解组件；本候选复用其数值部件，条件方程的适配仍由本项目验证。[官方 SCF 说明](https://pyscf.org/user/scf.html#converging-scf-iterations)不构成本项目变分性、稳定性或收敛保证。

## 验收范围

1. 工程测试禁止分子 SCF、格点构建和完整积分；用解析数组验证假收敛拒绝、真实端态、原阈值、周期/求值上限、复位和最终重查。
2. 新批次首先只执行一个乙烯 pilot 顺序诊断：独立普通态、优化/非优化两个同 D 算子对照、两个生产候选路径与独立完整条件参考。每一项原门槛分别记录。若失败，保留轨迹，不自动扩大体系或改科学规则。
3. 硬限额 1 CPU、1 GiB、零 swap、900 s/进程；7200 s 总账，科学进程最多 1 个。旧总账和全部失败文件必须先核对未变，新账引用其身份，时间余额不复用为自动重试。
4. 原镜像仅作固定依赖环境，干净 Git 导出只读挂载；新代码没有烘焙进镜像。非 root、离线、源码只读，容器删除后输出仍留在宿主。
