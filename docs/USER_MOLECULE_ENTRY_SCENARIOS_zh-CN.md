# 用户分子计算场景与边界

日期：2026-10-05；DRAFT-3 配套。下列是拟开发的使用场景，不是已实现或已验收的服务。以 [设计与验收合同](USER_MOLECULE_ENTRY_DESIGN_zh-CN.md)为执行边界。专业用户提出自己的问题，系统提供有明确条件的数值结果；不要求研究原著背景，也不替用户决定科学模型。条件态、占据和数值资格见 [操作性定义](USER_MOLECULE_CONDITION_DEFINITION_zh-CN.md)；与外部方法的关系见 [方法对照](USER_MOLECULE_METHOD_COMPARISON_zh-CN.md)。

LOCAL-MOLECULE-DETAILS-1：新增 C06 化学键微观研究应用专题，复用 C01—C03，实施顺序见 [本地细则](USER_MOLECULE_IMPLEMENTATION_DETAILS_zh-CN.md)。它不是新计算任务或范围扩张；本地 Docker/启动器优先，Colab 暂缓。

所有场景共同适用 A11—A13 的资源、隔离和持久性合同，以及 A15/A16 的溯源与交付声明。上表的“手工比较”不意味着已提供汇总工具；也不把额外请求默认为免费或无预算。

## C01 固定几何片段条件态对照（首个核心场景）

适合需求：用户已有一个关注片段耦合的平面不饱和 C/H 研究体系，想在指定 h/S/F 与十五类 ERI 删除模型下定量比较能量。平面 s-trans 丁二烯可作为待审小体系候选；名称不等于分片已被认可，更不证明该差值是唯一共轭能。

用户的最少决定：坐标、电荷/自旋、哪些碳属于 A/B、为什么采用该条件态定义。系统处理 AO 映射、固定 profile、资源、两态计算、诊断和记录。用户不需要阅读版本协议全集，但应能看懂一段条件态说明并确认问题。

成功交付示意（字段，不含虚构结果）：ordinary_energy_hartree、conditional_energy_hartree、delta_same_geometry_kcal_mol、两态 qualification、method_applicability、条件态能量账本。数值未计算，一律无示例预设正负或大小。

价值：给出指定模型的可核查结果与失败诊断，供用户与自己的研究假说关联。若方法适用性未审查，保留 EXPERIMENTAL_METHOD，不把输出当作理论定论。

## C02 分片定义敏感性（手工独立请求）

适合需求：同一分子存在两个有依据的片段划分，用户希望了解定义依赖程度。首版只执行单个请求；用户保存同一 geometry/profile 的两份结果，再做显式比较。

报告至少列两套原子清单、条件态定义、各自资格和同几何 ΔE。可以比较 ΔE(definition 2)−ΔE(definition 1)，但必须说明是模型定义差异，不称为能量测量误差。只有 A/B 名称互换而成员不变，应是不变量；真实成员改变则不要求数值不变。禁止按结果大小自动挑选分片或仅保留“理想”结果。

比较清单：实际几何快照、原子对应、calculation_profile/condition_profile、规则/来源及资格相同，仅碳组成员改变。分别保留 fragment/model 身份。完整合法的另一分片不应作为输入错误拒绝；意图由用户确认，范围是否允许另判。

## C03 用户提供几何响应（手工独立请求）

适合需求：用户已有同一分子的两个共面几何，想检查改变键长或其他平面参数后模型量如何响应。系统对 R1/R2 各做同几何两态比较；两次请求需分别通过资源和资格。

手工差值公式为 `[Eord(R2)−Econd(R2)]−[Eord(R1)−Econd(R1)]`。如果某次资格不通过，不组成合格对照。原子顺序不同时必须有显式映射；首版不实现自动匹配。用户提供构型不是本服务优化结果，不据此判定极小值、反应路径、热力学自由能或动力学势垒。

比较清单：元素和原子对应、碳组、profile、规则与科学来源相同，仅几何改变；展示 R1/R2 与人工确认的对应。文件哈希证明各自身份，不自动证明两个 XYZ 的原子对应。研究解释不得高于两次请求较低的资格。

## C04 同条件记录复现

适合需求：合作组提供了固定几何和条件态记录，需要独立再运行同一问题。仅在同几何、同分片、同方法实现、基组、网格、电子态与判据可确认时比较同一个量。缺失条件明确列 UNKNOWN，不把软件版本一致当作问题相同。

如果对方采用不同条件定义，只能标为方法对照、另行设计；不能将差异直接归因于环境失效。用户自有记录的分享由其自行授权，项目不自动上传。当前镜像未公开分发，外部研究者部署条件另行安排；不能提供尚不存在的公开镜像下载链接。

比较顺序：先核对科学来源/profile/规则、输入几何与原子对应、分片和各态状态，再按预登记数值容差比较。原字节差异、规范化几何差异和真实物理输入差异分别解释。同实现记录复现不替代独立条件核，也不替代 BLW/ALMO/NBO/cDFT 的方法关系审阅。

## C05 数值诊断与教学

适合需求：方法开发者、研究生或计算用户需要了解失败来自输入、普通态、条件态、屏蔽度量还是资源。pilot 提供低成本技术路径，真实失败按阶段报告；试跑结果不能自动作为研究级数据。

示例可用单片段内部控制、toy tensor 和两片段受控教学体系。单片段仅为内部验收，不是首版公开输入。教学坐标/请求必须显式标注用途，不能把“能计算”或“两个内存路径吻合”写成该化学模型普遍正确。

失败指引：字段/原子错误给位置；资源不足列预算及需求；数值失败列门禁/阶段/日志；方法未审列缺失范围。比较数值资格与研究资格分开展示；pilot 真实失败仍 NOT_QUALIFIED，不用 TECHNICAL_ONLY 掩盖失败。

## C06 化学键微观研究：电子耦合与条件态能量分析

适合需求：用户研究受审范围内平面不饱和 C/H 体系的化学键相关电子耦合，希望定量考察指定条件操作的能量响应。首版以 C01 为核心，必要时分别执行 C02/C03，手工关联记录；不新建批量扫描、键级计算或另一个 SCF 实现。

输入仍是固定 XYZ、两组碳编号、profile 及现有 research_question 备注。用户可说明关注的原子/键，但两组 π AO 操作并不自动对应一根物理键，服务不识别或补写唯一作用归属。输出仍为同几何全分子能量差和账本，研究简报强调定义依赖、资格和允许解释。

允许的结论示意是“在指定几何、分片和规则下，两计算态的模型能量差为此次真实结果；换分片/给定几何后的响应是所列差异”，不预填数值。“测得该键强度”“该差值就是键解离能”“已经证明唯一共轭贡献”等不在首版允许结论中。不同规则引起的差异不是仪器测量误差。

方法未审的请求保持 NOT_REVIEWED；获准的探索计算也只能按其实际资格判读。研究用途不能把 pilot 自动提升为研究结果。C06 的 A18 用户验收检查是否能区分模型条件量、研究解释与实验测量；不新增高成本夹具或改变 A01—A18。

电子密度/键级/局域轨道、键解离过程或实验信号需要分别定义基底、电子数/归一化、参照态、分析方法和独立证据，作为后续增强。当前条件密度在 S̃ 度量下合格不自动证明原 AO 物理布居可直接解释，相关输出尚未纳入服务。

## 适合立项但不属于首版的场景

| 后续需求 | 为什么要独立设计 |
|---|---|
| 非平面构象、扭转对照、通常的三维分子 | 现有 AO 奇偶分类依赖 xy 平面；自动旋转只能处理共面取向，不能使非平面模型成立 |
| 杂原子共轭体系、取代物、离子和自由基 | 元素/AO、片段化学定义、占据与条件核适用性未验证 |
| 用户两态结构优化与频率 | 需要一般几何自由度、梯度/数值导数、终止与稳定性独立验收；P14 五参数优化不能直接移植 |
| 通用结合能、反应能/势垒、溶剂/热力学性质 | 比较量、参照态及物理模型不同，不是单次条件态能量差能回答的问题 |
| 电子密度、键级、局域轨道与键解离能分析 | 分析定义、原 AO/屏蔽度量、归一化、参照态和必要修正须独立审查与验证 |
| 化学键实验微观测量、成像或信号解释 | 需要实验数据/模型、测量对象和校准验证；计算模型量不冒充测量值 |
| 自动扫描、批量分片、自动结构生成及多用户调度 | 新输入、资源、结果关联与科学选择合同；首版无相应执行器 |

这些是后续议题，不是本轮首版验收欠账。对请求不匹配的用户给出具体拒绝理由和边界，不引导其绕过门禁。

## 外部评审需要回答的场景问题

1. C01—C05 及复用它们的 C06 是否解决真实专业需求？C06 是否清楚限定模型量与化学键研究解释？
2. 同几何条件量与分片的表述是否足以避免物理含义误读？
3. 首批平面不饱和 C/H 方法域如何客观限定？未知用户分子应拒绝、探索性开放，还是要求额外审查？
4. C02/C03 的手工独立请求是否足够，能否推迟批量/汇总实现？
5. xy 定向要求是否可接受？若建议自动共面定向，应另列保持几何、映射及 AO 协变验收，不能静默投影。

评审只决定设计是否足以进入受控实施；不授予新科学结论、平台支持或公开发布权限。
