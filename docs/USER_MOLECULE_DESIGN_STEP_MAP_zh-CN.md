## 2. 按顺序完成什么

1. W01 保存当前基线和材料，建立隔离工作区。
2. W02 实现请求、输入检查、快照和检查回执；纯解析先行，AO 检查需要目标科学环境。
3. W03 实现科学适配器和明确的结果映射，不改变固定核来匹配预期。
4. W04 从干净提交构建新候选，接通启动器、资源限制、宿主监督和持久输出。
5. W05 以独立基础参考、小夹具、两存储路径和状态测试完成技术验证，pilot 为 TECHNICAL_ONLY。
6. W06 完成研究 profile 的完整独立条件参考、至少两个冻结新体系及方法范围审查。
7. W07 完成指南、真实样例、支持声明、候选与备份，使用户能独立操作和判读。

W01—W04 建设服务；W05—W06 检查实现及研究适用范围；W07 完成用户交付。部分工作可以穿插：先完成 W03 的 inspect 支撑检查候选，再完成 compute；完整依赖按技术方案第 11 节执行。

## 3. 一次用户操作经过哪些部件

```text
Check：   W02 输入和快照 → W03 inspect → W04 受限环境/记录 → 检查回执
Compute： W02 复核回执 → W04 执行监督 → W03 两态计算 → 资格/差值/记录
可信性：  W05 实现验证 + W06 研究范围与独立参考
使用：    W07 指南、简报判读与导出
```

“执行成功”“数值合格”和“研究适用”分别报告。合法输入不保证资源充分或方法适用；普通态不合格不进入条件态；必需门禁失败不输出合格差值。同定义参考检查代码，BLW/ALMO/NBO/cDFT 对照检查科学解释，不能相互替代。
