## 占据失败的具体位置

在两生产返回D对应的真条件算子F̃上，π AO为零起算索引4/9（用户查看编号为5/10）。跨片段F̃πAB为0，σ–π耦合极小。将保存的F̃、S̃按原SciPy默认下三角镜像，每个binary64元素转为精确有理数，验证LDL逐元素重构：以两个π对角广义能级中心±1e-10 Eh作诊断窗口，完整14维惯性负数由7变为9，而12维σ块两侧均为7。

因此，**保存矩阵的第8/9个广义能级均在这个窄窗口内，并跨过8占据/6虚轨道边界**。1e-10是只读谱定位窗口，不是新增验收门槛；这个定位针对已保存二进制矩阵，不证明未知精确物理算子严格简并，也不证明其他非对称自洽根不存在。

保存D的白化投影在该二维窄谱空间中的占据特征值约为`[0,1]`、迹为1；下方σ空间的占据数约为7。它占据的是π二维空间内的**一个方向**。两生产π密度块均近似：

```text
Dπ ≈ [[1,1],
      [1,1]]
Pπ ≈ Dπ/2 ≈ [[0.5,0.5],
             [0.5,0.5]]
```

这里本夹具S̃ππ≈I，σ–π度量耦合极小，才有上述Pπ≈Dπ/2；一般非正交AO度量下不使用这一恒等关系。

这个秩一投影不能由“π二维总子空间相同”唯一确定。在保持**已保存F̃不变**的代数见证中，选择几个不同窄谱方向，仍可得到16屏蔽电子、幂等以及约1e-14对易残差，但密度差可达约2。这些方向未重新求F(D)，只是说明小对易残差缺少选态信息；不是多个自洽根，不是新科学结果，不能择一回填通过。

原生产门禁的映射相对残差仍为0.429802860/0.433571473，最终gap仍约2.68e-15/5.63e-15，原门槛分别为2e-8和1e-6 Eh。NumPy只读诊断采用另外的白化/特征向量实现，不能替换保存的SciPy raw-map数值；窄谱内特征向量方向对舍入敏感，正式结果保留。

结论限定为：**V2修复了种子准入并使本次生产对易残差降小，但没有解决当前保存端点的全局Aufbau正能隙/占据选择验收。** 不能据此把整个乙烯分子列为永远不可计算，也不能用放宽gap、随意排序或MOM替换既有定义来通过本合同。

## 三种电子数与能量算子

COPY返回D的屏蔽、原AO及网格电子数分别约为：

| 度量 | 电子数 |
| --- | ---: |
| Tr(S̃D) | 16.0000000000 |
| Tr(SD) | 16.4745364598 |
| 原AO/grid积分 | 16.4745373392 |

原AO与屏蔽计数差约0.474536；网格与原AO计数差约8.79e-7。后二者接近不意味着均等于输入16；屏蔽计数通过不能替代物理电子数解释。这不是新增拒绝门槛，也不自动否定原P01—P14。服务当前不能据此给出已获准的物理基态、单键能或实验测量解释。

能量应明确称为**冻结条件能量：屏蔽h/ERI加原AO/grid XC**，不是普通态未屏蔽能量。旧“original-functional”措辞保留其历史身份，本页澄清所指对象。源码及独立参考给出：

```text
E(D)=Tr(h̃D)+½Tr(JD)−a/4 Tr(KD)+Esl(D)+Enuc
G(D)=h̃+J−a/2 K+Vsl
F̃(D)=Pmask(G(D))
```

若锁定固定网格的Esl/Vsl满足其导数合同，则`δE=Tr(GδD)`。全局S̃闭壳层流形上，允许48个占据—虚旋转κ，`δE=4⟨CvirᵀG Cocc,κ⟩F`。当前代码未要求`δD=Pmask(δD)`，所以一般不能由F̃残差小直接推导能量驻定；详见[既有推导](USER_MOLECULE_METHOD_REVIEW_20261006_zh-CN.public.md#4-能量算子关系的可核查判据)。

本次生产保存D上，G和F̃对易残差都约1.889e-9，删除部分Δ=G−F̃的切向块范数约1.8e-15/3.1e-15，`CvirᵀG Cocc`约1.036e-9。代数分解和G装配核对一致。**本例没有显示明显切向导数失配，不能将当前拒绝归因为这一问题。** 数值能量方向导数和二阶稳定性未执行，仍不登记能量驻定PASS或极小值。

保存G的只读广义谱gap约0.263430 Eh，其密度映射相对诊断约1.13e-9；这是**另一个算子**。G没有删除πAB元（约−0.131715 Eh），F̃删除了该元，而DπAB约1。G诊断不能替代F̃验收，不能为使当前端点通过而切换迭代算子；那将是另一个方法合同。
