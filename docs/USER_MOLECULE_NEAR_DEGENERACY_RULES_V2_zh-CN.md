## 1. 要计算的状态及本次改变

对象仍是固定几何、原子映射、原 AO/网格/XC、两组 π AO 与原 h/S/F 和十五类 ERI 条件规则下的**全局闭壳层2/0条件算子固定点候选**。偶数电子 N、占据维数 nocc=N/2。候选密度集合为对称半正定 D，满足 `Tr(S̃D)=N`、`DS̃D=2D`；S̃ 必须正定。没有指定片段电子数，也不额外要求 D 的跨组 π 块为零。

| 事项 | 明确规则 |
|---|---|
| 初始占据来源 | 使用已验收、锁定普通态缓存中的占据**列空间**，按 S̃ 重正交化 |
| 初始条件 F 的小能隙 | 记录诊断；不从其并列本征向量任意挑一列来定义种子 |
| 迭代占据 | 保持全局2/0、rank nocc投影；残差候选更新整个占据空间，不按片段重新填电子 |
| 最终占据目标 | 返回 D 上真实、未经过 DIIS 的 F̃(D) 的全局最低 nocc 广义谱投影，与返回 D 一致 |
| 最终 occupied/virtual gap | 仍须 ≥1e-6 Hartree；未过继续拒绝 |
| 排序、符号与内部旋转 | 比较密度和占据投影；MO符号、列顺序或整个已占据空间内部旋转不定义新态 |
| 部分占据简并簇 | 占据/空轨道混合可能改变 D；不能只因整个簇相同而判同态；本候选不接受最终边界近简并 |

这不是接纳零 gap 的新科学方法，也不增加 MOM、分数占据、smearing、level shift、破对称扰动、开壳层或块占据。若外审认为目标必须采用这些定义，应另立协议，不把它们加入本候选后仍称原规则通过。

## 2. 具体初始化定义

输入为同一锁定完整普通态缓存：D0、原 S、屏蔽 S̃、普通态 `mo_coefficients` 与 `mo_occupations`。首先核查文件及数组身份、有限性、维度、电子数、闭壳层占据与普通态资格。取 occ=2 的 nocc 列组成 C0；必须验证 `C0ᵀ S C0≈I` 和 `2C0C0ᵀ≈D0`。缺少已验证的轨道/占据时拒绝，不按轨道名称猜测，不使用来源不同的 C0。

定义种子 Gram 矩阵 **B=C0ᵀS̃C0**。只有 B 正定、满秩、有限并通过条件数护栏时，才计算：

```text
Cseed = C0 B^(-1/2)
Dseed = 2 Cseed Cseedᵀ = 2 C0 B^(-1) C0ᵀ
```

实现拟复用锁定 NumPy/SciPy 的对称矩阵分解和线性求解；不使用伪逆、裁剪特征值、加对角正则或投影修补以掩盖失败。S、S̃、B 的条件数上限候选为1e6，属该夹具的工程护栏，非普适科学门槛。输入与种子正交/重构核查的相对 Frobenius 候选容差为1e-10，分母 `max(||expected||F,1)`；正定性要求最小特征值严格>0。所有实际量和拒绝原因须登记。

逐项固定核查对象如下；没有把不同维度或归一化混用：

| actual | expected | 核查 |
|---|---|---|
| C0ᵀSC0 | I_nocc | 相对Frobenius ≤1e-10 |
| 2C0C0ᵀ | 缓存D0 | 相对Frobenius ≤1e-10 |
| CseedᵀS̃Cseed | I_nocc | 相对Frobenius ≤1e-10 |
| Dseed S̃ Dseed | 2Dseed | 相对Frobenius ≤1e-10；分母用 `max(||2Dseed||F,1)` |
| Qseed Qseedᵀ | Q0 Q0ᵀ | 相对Frobenius ≤1e-10；Q为相应列空间的欧氏正交基 |
| Tr(S̃Dseed) | N | 电子数绝对误差 ≤1e-7 |

种子幂等核查的归一化不替代下节已冻结的最终幂等公式，两阶段分开记录。

### 2.1 A02必须同时通过现有求解器准入

上表的种子定义检查和求解器入口检查是两层不同的量，必须分别记录并同时通过。电子数误差≤1e-7不替代白化投影迹误差≤1e-10；AO相对幂等残差不替代白化投影的绝对幂等缺陷。现有生产与独立参考代码均不调整。

令 `H=S̃^(1/2)`、`X=S̃^(-1/2)`、`Pseed=0.5 H Dseed H`，`nocc=N/2`。两生产存储路径和独立参考的实际准入结果分列：

| 现有求解器准入项 | 定义与原门槛 | 适用路径 |
|---|---|---|
| 输入矩阵/配置 | 实有限同维对称Dseed/S̃，矩阵对称绝对容差1e-12；S̃严格正定；偶数闭壳层、至少一个虚轨道，占/虚旋转变量≤64；白化量有限 | 两生产路径、独立参考 |
| 白化投影迹 | `|Tr(Pseed)−nocc|≤1e-10`，绝对误差，无归一化 | 两生产路径、独立参考 |
| 白化投影幂等 | `||Pseed²−Pseed||F≤1e-10`，绝对Frobenius范数，无归一化 | 两生产路径、独立参考 |
| 生产密度重构 | 对sym(Pseed)取最高nocc本征向量Uocc；`Drec=2 X Uocc Uoccᵀ Xᵀ`必须有限，`||Drec−Dseed||F/max(||Dseed||F,1)≤1e-10` | 两生产路径；当前独立参考没有这一额外入口检查 |

逐路径登记实际输入身份、每个量的公式/度量/分母/原门槛/测量值/通过或拒绝，以及代码提交和来源位置。当前实现来源：`runtime/user_molecule/residual_candidate.py`入口、`residual_bridge.py`的准备态检查，及`reference/residual_candidate.py:frame`。所有必需项须在该路径首次功能式回调前通过；失败则该路径零F调用拒绝，不投影修补、不减小精度要求。独立参考缺少生产重构检查须明确标为该路径原实现未设此项，不能补造PASS。

白化投影迹误差约束的是占据轨道数N/2。精确算术下 `Tr(S̃Dseed)−N=2[Tr(Pseed)−N/2]`，电子数误差是投影迹误差的两倍；浮点求值和范数不同，不能以代数换算代替逐项实测。两层检查、最终端态门禁和数值合格分别记录，禁止合并为一个“种子PASS”。新候选A02的这些检查尚未执行。

在精确代数中：

```text
Tr(S̃Dseed) = 2 Tr(B B^(-1)) = N
Dseed S̃ Dseed = 2Dseed
range(Dseed) = range(C0)
```

种子只依赖普通态占据列空间：C0→C0A（A可逆）时，公式给出的 Dseed 不变。该不变性是内部表示的代数性质；输入验收仍要求缓存的物理度量归一化和 D0 重构，不能把任意非正交列变换直接冒充原缓存 MO。

`Dseed` 是新初值，**不是把 D0 原样当成已合格条件态**。原 D0 字节、其物理 S 下电子数16及屏蔽 S̃ 下电子数15.616464362098597的历史诊断保留。新种子另存身份、父来源、矩阵检查和政策版本。`Tr(SDseed)` 与原 AO 网格电子数继续分别诊断；不能因屏蔽度量守恒，声称原 AO 密度物理电子数也自动等于 N。

首轮 F̃(Dseed) 的实际求值消耗新预算。它的 gap 可以近零，只作初始诊断；它没有赋予最终资格。残差求解若在驻点停止但最终门禁失败，仍返回拒绝。种子可能仍不收敛或最终 gap 不合格，本设计不预设乙烯必然通过。

## 3. 保留的最终验收合同

F̃与能量必须绑定**返回的同一 D***，不得用 DIIS 算子、其他试步密度或最后一个任意回调替代。未通过必要项则 `engine_qualified=false`。

| 必需项 | 定义/保留阈值 |
|---|---|
| 原始 AO 对易子 | `||F̃ D* S̃−S̃ D* F̃||F ≤1e-5` |
| 屏蔽度量电子数 | `|Tr(S̃D*)−N| ≤1e-7` |
| 闭壳层幂等性 | `||D*S̃D*−2D*||F/max(||D*||F,1) ≤1e-7` |
| 能量账本闭合 | 五项和与总能差 ≤1e-9 Hartree |
| S̃/F̃禁止块 | 各最大绝对元 ≤1e-12；D禁止块未加新门禁 |
| 真实全局 Aufbau 映射 | `Draw`由 F̃(D*) 的最低 nocc 广义轨道产生；相对差 `||Draw−D*||F/max(||Draw||F,1) ≤2e-8`，绝对差 ≤2e-8 |
| 最终条件能隙 | F̃(D*) occupied/virtual gap ≥1e-6 Hartree |
| 真算子能量重检 | 返回 D 的重检能差及 Draw 重检与 D* 能差分别 ≤1e-9 Hartree；重检同样收费 |
| 映射密度完整重检 | 在Draw上重求真实F(Draw)，再次通过全部原endpoint gates，包括再次raw-map相对/绝对残差、gap、守恒/幂等/闭合/mask；其raw-map绝对差仍≤2e-8 |
| 来源与有限性 | geometry/profile/source/dependency/初值身份一致；必需量非有限或未知即拒绝 |

初始与最终的 gap 是不同阶段。仅把新初始化的 gap 从拒绝条件改为诊断，**不把最终1e-6门槛改小或删除**。旧 `FIRST_RAW_GLOBAL_AUFBAU_AT_ORDINARY_D0` 政策、旧三路径拒绝以及所有旧合同/预算保留，不追认通过。

编号约定：**UM-P12**是用户入口的ERI存储路径能量一致性验收，**UM-P13**是该入口的ERI存储路径密度一致性验收；两者与原项目的P12、P13科学命题不是同一编号空间。冻结JSON及历史结果里的`P12/P13`机器键保留，本文用前缀明确其用途，不重命名历史证据。

UM-P12/UM-P13比较两生产存储路径；T06另比较生产路径与独立参考。

比较要求：三个端点各自合格后，才用同一占据投影和用户入口原 UM-P12=1e-10 Hartree、UM-P13=1e-9 Frobenius、T06能量=1e-8 Hartree/分项=1e-6/密度与F=1e-6的门槛比较。同根未确认则 `ROOT_NOT_COMPARABLE`，不平均根或偷偷交换原子。此段T05/T06也指用户入口验收项；相同 D 的完整T05另验收，本轮既有子范围PASS不顶替其缺项。

## 4. 能量和科学声明目标

初步可审解释只限“指定条件算子固定点上的原核功能式值及固定几何操作性响应”。是否允许对外报告 Eordinary−Econditional，仍取决于方法责任人的用途定义和外审意见。当前正式科研差值保持空值。

原核的能量形式导数 G 与迭代算子 F̃=Pmask(G) 不同。F̃固定点、账本闭合、低能量或正gap都不能独立证明所报 E 驻定、稳定或最低。要声称驻定，须对已定义允许变化核查 `Cvirᵀ(G−F̃)Cocc` 或等价导数关系；要声称稳定极小值，还需专门的稳定性证据。本候选不增加未经审阅的数值驻定/稳定门槛，也不先宣称这些性质。

允许的技术成功状态为 `QUALIFIED_CONDITIONAL_FIXED_POINT_CANDIDATE`；不称物理基态、稳定能量最小值、化学键能、实验微观测量或 BLW/ALMO/NBO/cDFT 等价。本页的阈值与公式是代理提出的待审合同，不填为责任人已经批准。

## 6. 成熟方法依据与外审范围

MOM/IMOM用于控制迭代占据跟随，与本候选的单次初值转换不同；官方文档表明它改变轨道选择步骤，不能把启用它当成不涉及状态定义的普通参数调整。[Q-Chem 7.0 官方手册](https://manual.q-chem.com/latest/topic_mom.html)、[Gilbert、Besley、Gill 原始MOM论文](https://pubs.acs.org/doi/10.1021/jp801738f)。

PySCF已有跟随占据和分数占据工具，可以作为备选研究参照；本候选不调用它们，也不把现成工具视为支持本项目屏蔽度量/原XC定义的证明。[PySCF官方源码](https://pyscf.org/_modules/pyscf/scf/addons.html)。SCF收敛与稳定性是不同问题，符合本页分开声明的要求。[PySCF稳定性说明](https://pyscf.org/user/scf.html#stability-analysis)。资料查阅日期2026-10-06；在线版本不是本机锁定版本认证。

外审限于本项目条件核、该初始化候选、最终目标与能量解释的相容性。原P01—P14不自动重新认证或推翻；明确发现共享关联问题后再单独分析。WSLc、WSL升级和发布不属此次范围。
