## 1. 推荐推进顺序

1. **先定条件态与解释范围。** 方法责任人回答全局/分块允许变化、预期占据、最终 gap 与可比根的要求，登记身份/职责/日期/理由。原 E/h/S/F/ERI/XC/全局 2/0 与门槛保留；需要改变则另立科学协议。当前签署字段为空。
2. **再设计原方程的残差求解候选。** 在 S̃ 闭壳层占据 projector 流形上用轨道旋转或受保护的真残差迭代，目标为 `Cvirᵀ F̃(D) Cocc=0`，不以 E 必须下降为普遍前提。该驻定方程可能给出激发 determinant，因此终态必须再验原全局 Aufbau map、全部真实端点 gate 与正 gap，不能以 comm 小替代最低占据。此方案未实现、不承诺能收敛。
3. **完成适配与受限工程验证后，才登记新科学合同。** 新合同需精确代码/依赖/夹具/初始 D/比较与状态选择身份、求解策略参数、总求值/周期/进程/内存/时间限额；父旧预算与失败材料不得重置。本页不是可执行合同，也没有把旧余额转成重试次数。
4. **首次新分子试验只做已冻结最小夹具。** 通过独立参考和两路径验收后，才做分模式资源校准；再完成两个合格研究体系、真实专业用户试用及解释范围确认，进入 W07。失败则保存轨迹和拒绝原因，不自动换体系或调门槛。

- 当前、候选与返回 D 的真实 F̃ comm、原 Aufbau map 残差、电子数/幂等/账本/屏蔽 gate，DIIS 算子谱另名保存。
- 相邻候选占据 projector 距离，候选与真实 F̃(candidate) 重映射距离，以及跨实现同周期相同定义的距离；避免轨道符号和内部旋转造成假差异。
- G−F̃、G 的 comm、相关占虚块，仅作允许变化/导数诊断；没有责任人审定与新版 gate 前不加入通行门禁。
- 每个真实/外推/试步算子、DIIS 条件诊断、拒绝/复位理由、求值次数与累计预算；保存足够轨迹后再判断循环或根分岔。
