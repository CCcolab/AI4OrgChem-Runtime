## 1. 服务目标和“化学键微观研究”的含义

专业用户在本地提交自己的固定几何分子，确认两个碳 π 组及条件定义，获得普通态和条件态能量、同几何差值、数值资格与可追溯报告。主路径为“XYZ → 请求模板 → 检查 → 计算 → 简报与完整记录”；不要求先读原著背景、逐份核对历史协议或学习 Notebook。

正式纳入的应用专题 C06 名为 **“面向化学键微观研究的电子耦合与条件态能量分析”**。首版复用 C01—C03：考察指定规则的能量响应、分片定义敏感性、用户给定几何的响应；C04/C05 提供复现和诊断。C06 是研究用途和报告判读合同，不是第八个登记任务，也不新增科学算法或自由选择删除规则。

| 用户研究问题 | 首版可交付的计算量 | 允许解释及限制 |
|---|---|---|
| 指定片段间条件操作对能量有何影响？ | 同一 R 上 Eordinary、Econditional、ΔE 及条件账本 | 指定模型的全分子能量响应；不能分配为某一根键的唯一能量 |
| 换一套有依据的分片，判断是否敏感？ | 同几何/来源/profile 下两份独立请求的 ΔE 差异 | 条件定义依赖；不称测量误差或自动择优分片 |
| 两个已给定平面几何下响应如何变化？ | 每个 R 的两态差值及跨几何差分 | 给定几何响应；不是优化、反应势垒或完整势能面 |

首版比较量固定为 `ΔE(R)=Eordinary(R)−Econditional(R)`，原值 Eh，转换为 kcal/mol并记录常数。两态的同几何核排斥、输入及 profile 必须一致。屏蔽 h/S/F 与十五类 ERI 的指定操作不等于实验切断一条化学键；模型量不能直接冠以“实测键能”“键解离能”“唯一共轭能”或“普遍芳香性指标”。正负号和大小如实报告，不按预期调整规则。

条件固定点的能量—算子/占据解释仍待 A01/A06 审阅；variational_status=NOT_ESTABLISHED，稳定性分析 NOT_EXECUTED。方法范围批准前不生成研究就绪声明。既不把未证明写成已发现错误，也不以收敛或账本闭合代替科学解释依据。

电子密度差、键级、局域轨道分析、键解离能与实验信号对接是后续独立议题，不随 C06 自动实现。特别是条件电子数使用 S̃ 度量，而原 AO 密度和 XC 使用原基底；未来开展密度/布居解释前须审查 Tr(SDcond)、归一化与所选分析方法，不能直接把两态矩阵差当作已验证的实验电荷转移。

## 5. 测试、参考和资源安排

验证先低成本后真实小任务：解析/路径/状态与不变量 → toy/固定密度分量 → 普通态 → 两 ERI 路径 → 独立条件参考 → 新容器故障/用户操作。按阶段执行有意义的用例，旧 L3/L4 记录只读引用。

至少两份冻结新平面 C/H 夹具及分片由 D0/A01 审阅，候选是平面 s-trans 丁二烯与第二小体系；乙烯两碳分组只作为数学控制候选，不因能算就认可切断双键的能量解释。坐标/编号/profile/预期接受拒绝/数值容差/参考代码及预算先登记。不能把被测程序首次输出作为唯一 expected。

沿用参考合同的候选预算：独立标量参考 nAO≤40、单线程、4 GiB、每次≤900 s；普通/路径比较 nAO≤80、最多两线程、4 GiB、每次≤900 s；单轮所有新科学进程累计 wall-clock≤7200 s（含数值导数）。这是待审上限，不是实际所需内存或预计耗时；低于受测规模才可能启用，资源不足缩小夹具或另审预算，不能自动加资源或放宽容差。

资源校准作为 D2 内受控试验：先冻结校准样例、容器内存/线程/时限及宿主余量，再测各 ERI 模式峰值并更新受测规模。完整 ERI 的 8nAO^4 仅为单张量下限，不能当进程峰值；max_memory/线程环境变量也不是硬内存/CPU 配额。未校准的用户规模保持 BLOCKED，不因有 Docker 就直接放行。

宿主监督端在计算容器之外先写 run ID、container ID、输入与命令，保存实际退出码、OOM 标志、分态/阶段、已存在文件和哈希；取消只针对本次已保存 ID，不按名字杀其他科研进程。未知原因写 UNKNOWN，不要求被杀进程自己完成 manifest；容器删除后输出仍可核对。受限故障不压满主机/WSL VM。

候选 SCF/残差阈值及两 ERI 路径比较按主合同和操作性定义冻结后执行，不在此另设一套容差。同数学定义独立实现检验代码，BLW/ALMO/NBO/cDFT 等检验方法解释；方法关系审阅必需，不统一要求安装或计算所有外部程序，也不以接近数值证明等价。
