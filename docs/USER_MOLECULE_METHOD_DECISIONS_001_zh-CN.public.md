## 3. 能隙与目标条件态相容性须先审

现行冻结 gate 是返回 D 上、未经过 DIIS 的 **投影条件算子 F̃(D)** 的 occupied/virtual gap ≥1e-6 Eh。它不使用投影前 G，也不使用末次 DIIS 算子的 gap。

三个事实必须分开：

1. 保存的初始 F̃(D0) 第 8/9 谱位于同一中心 ±1e-10 Eh 窗口，只证明保存算子的初始占据边界很窄；不证明最终固定点必有零 gap。
2. 在最终自洽 D* 上，若目标端态确实要求严格对称、σ/π 解耦、F̃ 与 S̃ 的 πA—πB 交叉块为零、两个相同的 π 算子/度量块，并在该 π 对中占据一个轨道而另一个未占据，则这一对的 gap=0。**如果**它同时构成全局占据边界，就与现行正 gap gate 冲突。现冻结 mask 提供交叉块为零，但尚未证明该自洽端态及其余前提成立。几何对称也不单独保证非对称占据 D* 所生成的最终算子两块相同。
3. 当前实际最终三端态的 gap≈0.301—0.314 Eh，gap gate 已通过；失败在真实 comm/占据 map 等 gate。因此，不能把“门槛冲突可能性”写成已确认的本次数值失败原因。

D04 须把每个前提逐项标为已证明、需补证或不适用，并给出结论 `COMPATIBLE / INCOMPATIBLE / UNRESOLVED`。只要未解决，就不靠更换求解器来关闭此项。若决定改占据、允许变化、算子或 gate，则建立新科学/验收协议版本；旧合同、旧 FAIL、旧 delta=null 留存，不追认通过。本轮所有原参数不变。
