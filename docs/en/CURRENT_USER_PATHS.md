# Three user paths

1. **New user:** follow [source installation](SOURCE_INSTALLATION.md), then the [four-step RHF workflow](CURRENT_MOLECULAR_SINGLE_POINT.md). Prepare XYZ/request, read the report and retain the complete records. Closed-shell singlet is your model assumption, not automatic ground-state identification.
2. **Professional user:** use the [service matrix](CURRENT_PROFESSIONAL_SERVICES.md) to choose [fixed examples](CURRENT_REGISTERED_CASES.md), [protocol cases](CURRENT_PROTOCOL_CASES.md), or [high-cost fixed states](CURRENT_HIGH_COST_CASES.md). Compare objects, methods, ledgers and qualification scope. Registered P11/P12 entries do not mean all 78 states passed. The [original P14 contract](CURRENT_P14_BUILD_RUN.md) has its own identity and environment.
3. **Developer/maintainer:** inspect [locks](../../locks), [exact installation bindings](../../scripts/installation_source_bindings.py), [public CI](../../.github/workflows/validate.yml) and [test distribution scope](TEST_DISTRIBUTION.md). Runtime root tests remain local. Two public engineering jobs do not cover all science or private unit suites. Changes to science/source/algorithm need their own protocol; do not simply refresh hashes to bypass mismatches.

The historical S1–S6 seven-task path does not replace these current entries. The website does not run online calculations. User conditional Compute remains closed; platform upgrades and public image distribution retain their current boundaries.
