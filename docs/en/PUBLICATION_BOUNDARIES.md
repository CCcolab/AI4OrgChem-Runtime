# Source publication, image distribution and local candidates

Source and the static guide are public in [CCcolab/AI4OrgChem-Runtime](https://github.com/CCcolab/AI4OrgChem-Runtime), under owner authorization. GitHub Pages serves guidance and local commands, not online molecular calculations. The current public scope describes actual Docker computation and separately recorded ordinary WSL2 Check; one platform's checks do not qualify another.

Public files include Runtime-owned code, source/dependency locks, user documentation, attributed third-party materials and selected review evidence. They do not include a complete local environment, Docker image, downloaded dependency-source archives, all run logs/checkpoints or original development workspaces. Minimal numerical witnesses support saved-data matrix/ledger review, not new science calls. Raw/derived identities and missing evidence remain separate. Withdrawn candidate-platform materials are preserved locally; removing active files does not remove public Git history or rewrite old evidence.

Git clone supplies source/history. The dedicated installation ZIP adds Git-object proofs, not a complete installed environment. Source publication does not imply public images or acceptance of every registered state/arbitrary molecule. v0.1.0 source/guide Release and tag have explicit owner authorization; that authorization excludes images. See [release scope](RELEASE_v0.1.0.md).

## Engineering and science

Current public CI has two engineering jobs; see [test distribution](TEST_DISTRIBUTION.md) and actual run-linked records in the repository. Historical three/four-job runs keep their original commit/scope. Pipelines build/test and may upload bounded evidence; they do not push images, tag versions or publish Releases. Manual authorized release publication is separate.

Ordinary RHF supports the initial small-system profile, with same-PySCF wrapper controls and no wavefunction-stability certification. Fixed protocols retain their own input/image scope. Two high-cost pilots do not qualify 78 registered states. Conditional user Compute lacks a qualified endpoint and remains closed; original P01–P14 are not automatically reopened. L4 saves checkpoints without resume.

## Remaining prebuilt-image distribution blockers

Distribution remains `BLOCKED_LOCAL_ONLY`. Preserve these concrete unresolved items:

1. Exact source versions, patches and build records for some wheel-bundled libgfortran/libgomp/libquadmath; Debian gcc-12 source is not proof of their corresponding sources.
2. Exact SciPy OpenBLAS development commit and actual NumPy/PySCF BLAS build provenance; parent sdist/filenames are insufficient.
3. h5py's immutable HDF5 build-image identity and actual libaec/libsz versions/patches.
4. PySCF native build options and evidence of whether XCFun patches were applied to the actual wheel.
5. Recipient-accessible complete notices, applicable corresponding sources and LGPL modification/relink conditions; a local supplemental path is not public delivery. Additional components/fonts remain in the original component addendum.

Previously acquired exact Debian/Python sources, signatures, vendor notices and license materials remain credited; this is not a claim that every source is missing. Root Apache-2.0 covers Runtime-owned code only. Third-party files retain their own terms; see [LICENSE](../../LICENSE), [NOTICE](../../NOTICE), [compliance](../../compliance/README.md) and [license review](LICENSE_REVIEW.md).

Future image distribution additionally needs registry/access/visibility review, explicit authorization, an actual push/pull and registry digest evidence. Existing candidate packages/exports/backups retain their original source/build/run identities. Same-disk backup is not a recovery acceptance.

Independent storage, actual restore rehearsals, signing/attestations, portable SBOM and automated publishing are later enhancements. Strict offline L3/L4 and full L4 interruption acceptance remain unexecuted; resume is outside the current contract. Private root Runtime tests remain local; frozen upstream tests are a separate source scope.
