AI4OrgChem Runtime

Run scoped molecular calculations on your own computer and review registered research examples. Keep scientific sources, inputs, dependencies, logs and results traceable.

This website is a usage guide. It does not upload molecules or execute online calculations.

Start in three steps

  1. Install from source using existing Python 3.12+ and Docker Linux/amd64. Build locally and register your service image; no prebuilt public image is supplied.
  2. Choose your own molecule or a fixed research module below. Follow its English guide using the same installation record.
  3. Retain the complete new run directory and read result interpretation and the review template.
