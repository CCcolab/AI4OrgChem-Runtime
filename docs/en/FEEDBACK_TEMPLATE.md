# Review feedback template

Fill manually and review before sharing. This template does not send/upload messages or request calculations automatically. Inspect personal paths, credentials and unpublished material; use a redacted copy when necessary, retaining original hashes and a redaction note.

- Category: evidence navigation / scientific rules or numerical checks / startup/platform / resources / output/identity / documentation / independent future exploration.
- Task, run ID, report date and platform/engine version; unexecuted work: NOT_EXECUTED.
- Scientific source commit, image-build Runtime commit and host launcher commit, or UNKNOWN.
- Local image ID, registry digest if any, actual dependencies and lock SHA-256 separately.
- Exact command/parameters, output root and parent-run relationships; inspect paths before sharing.
- Expected behavior and fixed protocol/code basis; do not just write “expected PASS”.
- Actual status, process/runtime exits, qualification, classification and failed checks.
- For science issues: method/basis/grid/constraints/comparison/reference/differences/units; otherwise NOT_APPLICABLE.
- Recorded effective memory, threads, peak/time and network conditions, or UNKNOWN.
- Minimal evidence filenames and hashes: manifest, relevant result/report and necessary logs. Evidence/core tests without a result need actual logs.
- Checkpoint-only state, if applicable; L4 cannot resume.
- Specific question for review.

Locate scientific-rule issues in the pinned upstream protocol/code and launcher/resource/path/identity issues in Runtime. New molecules, methods or scans are independent proposals rather than changes to previously accepted cases. Source and image distribution have separate authorization boundaries.
