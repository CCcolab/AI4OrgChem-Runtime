外部浏览器的 ZIP 和独立 HTML 下载均曾被头部完整性检查拒绝；此前本地成功记录按原字节保留。本轮不能确认该浏览器中的确切原因，也不将本地通过写成对方环境复测通过。

在已有本地 Edge 中，向旧网页注入额外空样式节点可复现同类拒绝。修订版明确标识自有编码、视口、标题及内联样式，导出仅携带这些自有头部元素及登记脚本，不将额外浏览器样式或元数据误作必需内容。自有样式缺失或为空仍拒绝，组装前后及序列化复读仍逐项比较。

错误明确分为 `EXPORT_SOURCE`、`EXPORT_ASSEMBLED`、`EXPORT_SERIALIZED`，并列出缺项或不一致项。日志仅包含头部元数据，不读取或上传用户分子文件。
