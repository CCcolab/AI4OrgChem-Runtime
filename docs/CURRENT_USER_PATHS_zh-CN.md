# 当前三类用户路径

1. 普通用户：从[源码安装](SOURCE_INSTALLATION_zh-CN.md)进入[自己的分子 RHF 四步](CURRENT_MOLECULAR_SINGLE_POINT_zh-CN.md)，准备 XYZ/request，读取报告并保留 records。闭壳层单重态是模型假设，不自动识别真实基态。
2. 专业用户：按[专业服务矩阵](CURRENT_PROFESSIONAL_SERVICES_zh-CN.md)选择[固定案例](CURRENT_REGISTERED_CASES_zh-CN.md)、[专题协议](CURRENT_PROTOCOL_CASES_zh-CN.md)或[高成本固定体系](CURRENT_HIGH_COST_CASES_zh-CN.md)。比较方法、对象、账本和资格范围；高成本已有 P11/P12 入口，不代表78态已验收。原七任务／P14见[独立身份合同](CURRENT_P14_BUILD_RUN_zh-CN.md)。
3. 开发者／维护者：读取[来源锁](../locks)、[精确安装来源绑定](../scripts/installation_source_bindings.py)、[公开安装工程 CI](../.github/workflows/validate.yml)及[本地测试分发边界](TEST_DISTRIBUTION_zh-CN.md)。Runtime 根 tests 保留本地，不恢复公开；公开 CI 两个工程任务不覆盖全部科学服务或私有单元套件。科学来源和算法变动须有独立协议，不可任意刷新哈希。

旧 S1—S6 七任务阅读路径与旧目录状态是[历史材料](USER_PATHS_zh-CN.public.md)，不能替代当前入口。网页只作指南，不提供在线计算。用户条件态 Compute 仍关闭，平台升级与镜像公开分发继续沿用当前边界。
