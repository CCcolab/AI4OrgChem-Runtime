# 本地历史归档与当前公开范围

当前项目提供 Docker 计算入口，以及普通 WSL2 的原生环境只读检查。尚未交付的候选平台已从当前文件树、能力表、脚本、网页和下载材料撤下；本轮不升级系统或调整全局配置。

撤下前的完整文件树已在本地按 Git 原件保存，绑定提交 `eb65b4586c83637569f6359814338c1292948861`。本地归档 `pre-withdrawal-git-tree.zip` 包含 883 个文件，逐成员 CRC 和 SHA-256 已核对；ZIP SHA-256 为 `9528a59d29b92599d17c9dbdfcb7a9870b0a153e7b27fa59dd710cf5456497f3`。归档、原件清单和原 Windows 测试回执保存在项目的独立本地交付目录，不随公开文件树发布。

历史资料需要说明仍有效的科学定义、数值或来源时，当前版本提供名称含 `.public` 的阅读节选。JSON 中的 `_public_projection` 与 [公开副本索引](../validation/public-projections-20261010.json) 登记原件和节选各自的身份。节选不是原始运行文件；旧记录中的运行、构建和镜像身份仍属于当时环境，不能赋予当前安装科学资格。

[最小数值见证](../evidence/numerical-witnesses/README.md)保留原始矩阵载荷，三个父记录使用单独哈希的公开摘要，并另存原件哈希。只读复核不启动 SCF、积分或网格；被拒绝的条件端点仍被拒绝。

完整 W05 历史设计原文仅由显式本地归档访问；公开安装的默认历史读取会明确拒绝，不再报告这些原件已经在公开 CI 中逐字验收。

本轮不改写旧 Git 提交。旧版本仍可检索到撤下前的内容；当前文件树清理不等于历史删除。若以后改变完整历史的公开范围，应另行确认，不能把此次整理描述为历史擦除。
