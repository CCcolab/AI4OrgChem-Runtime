# 用户指南导入与当前维护范围

指南由用户提供的 YouMind 网页候选演进，原材料和历史字节保留于本地归档及既有 Git 历史。旧 source/archive 已不在当前公开目录，不伪称当前仍提供该目录。

当前公开站点为 https://cccolab.github.io/AI4OrgChem-Runtime/ 。自有维护源是 docs/index.html；实际下载核验后的十成员维护副本位于 docs/runtime-guide/current，静态 ZIP 位于 current-guide.zip。新增修改在本地核验后按已有公开授权同步源码／Pages；v0.1.0源码与指南Release及对应标签已由项目负责人另行授权，范围见docs/RELEASE_v0.1.0_zh-CN.md；不包含镜像分发。

YouMind 材料的来源、署名与授权边界独立保留，不自动改为根 Apache-2.0；当前维护文件不是完整运行档案或环境安装包。动态导出、静态文件身份和每次浏览器观察各有自己的验证记录。未复测环境不继承其他浏览器 PASS。

根 Runtime tests 不公开分发，CI、源码、网页和镜像分发是不同范围。指南不会执行计算、上传分子、自动安装或升级平台。L4 仅可保存检查点，不支持恢复。

原失败浏览器的三个动态下载及实际文件已由外部审阅者经项目负责人报告补验通过；当前问题登记为限定PASS，见[补验记录](../../validation/web-guide/external-browser-retest-20261010.json)。原失败和旧字节记录保留；发布链接文字更新后的新导出字节另记，不自动继承旧哈希。
