# P11-B 2007方法全平面受限优化复算协议 v0.2

## 目的

本协议解决P11-B中氰苯整体ESE、氰苯孤立苯环ESE、苯ESE及由此定义的CE与IE。旧结果使用Figure 7重原子键长重构后的固定完整几何，不能代替2007方法中每个条件电子态各自进行的受限几何优化。

## 唯一计算口径

- B3LYP/6-31G(d)，气相闭壳层RKS；
- 每次SCF迭代将不同局域π片段之间的Fock矩阵与overlap矩阵元置零；
- 不删除双电子积分，不屏蔽物理一电子算符；
- 苯与氰苯使用完全相同的实现；
- 所有原子的z坐标以Cartesian硬约束固定为0，只允许平面内几何自由度优化。

## 状态与公式

氰苯整体使用G、GL-I、GE1、GE2、GE3：

`ESE(SB) = (E_G-E_GLI) - sum(i=1..3; E_GEi-E_GLI)`。

苯使用G、GL、GE1：

`ESE(Bz) = (E_G-E_GL) - 3(E_GE1-E_GL)`。

氰苯孤立苯环使用GL-II、GE4、GE5、GE6、GE7：

`ESE(Ph) = (E_GE7-E_GLII) - sum(i=4..6; E_GEi-E_GLII)`。

共轭效应：

`CE = ESE(SB) - ESE(Ph)`。

诱导效应：

`IE = ESE(Ph) - ESE(Bz)`。

正IE表示取代苯中的孤立苯环ESE绝对值小于苯，即相对去稳定。

## 几何与可核查性

氰苯各态从原著Figure 7公开的重原子键长重构结构出发；苯从2007 Supporting Information的优化结构出发。每一步记录能量、梯度与最大面外偏差。最终结构须保持全平面。

初始协议还设置了“优化后任一环键相对Figure 7起始值变化不超过0.001 Å”的诊断阈值。完整计算中最大变化为0.002328 Å，来自氰苯G态，故该诊断明确记为未满足，阈值不作事后放宽。Figure 7只公开四舍五入的重原子键长，未公开完整Cartesian坐标与氢坐标；因此该指标用于披露source-start重构敏感性，不取代收敛性、平面性及ESE/CE/IE估计量验收，也不阻断科学定判。

## 证据处置

本复算保留旧固定几何代理记录用于审计，但旧记录不再用于2007方法的IE定判。本协议不改变P11-A，不生成AI训练标签，也不扩展其他取代苯。
