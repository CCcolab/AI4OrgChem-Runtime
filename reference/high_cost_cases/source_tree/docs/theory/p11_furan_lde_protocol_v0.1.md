- 日期：2026-08-21
- 状态：已冻结；仅授权单一呋喃G/GL/GE路径
- 原著程序代码：不使用

## 1. 原著命题纠偏

P11-A不采用“呋喃介于芳香与非芳香之间”这一非公式化转述。原著公开书稿给出的可证伪命题是：对furan-like species，`ΔEA=E(G)-E(GL)>0`、各局域增量`ΔEAm>0`、且`ΔEA<ΣΔEAm`；因此`ΔEA-ΣΔEAm<0`应命名为less destabilization energy（LDE），不能与苯型ESE直接比较，也不能据此把该类分子归为原著定义下的芳香分子。

## 2. 唯一计算对象与方法

- 分子：furan（C4H4O），气相闭壳层单重态；
- 方法：Gaussian风格B3LYP，即PySCF `B3LYPG/6-31G(d)`，grid level 3；
- 状态语义：原著2007 restricted-geometry语义，只屏蔽不同π片段间的AO Fock/one-electron/overlap块，不删除两电子交换积分；
- 几何：所有G、GL、GE均在同一平面C2v八参数空间独立优化；
- π片段：氧p型孤对电子组`O`，两个C=C组`A=(C2,C3)`与`B=(C4,C5)`。

状态定义：

- `G`：普通未屏蔽基态；
- `GL`：`O/A/B`三组彼此局域；
- `GE1`：只允许`A-B`局域双键对相互作用，`O`仍隔离；
- `GE2`：只允许`O-A`相互作用，`B`仍隔离；由C2v对称性，`GE3(O-B)`与GE2等价。

计算量：

`ΔEA = E(G)-E(GL)`

`ΔEA1 = E(GE1)-E(GL)`

`ΔEA2 = E(GE2)-E(GL) = ΔEA3`

`ΣΔEAm = ΔEA1 + 2ΔEA2`

`LDE = ΔEA - ΣΔEAm`

## 3. 验收与盲比较

- 四个几何优化均成功、无参数触边，最大有限差分梯度不大于`3.5e-4 Eh/Å`；
- 四个SCF态收敛，屏蔽度量电子数为36，跨片段π块为零，能量分量闭合；
- 2007分支的两电子积分删除数必须为零；
- `ΔEA>0`、`ΔEA1>0`、`ΔEA2>0`、`ΣΔEAm>ΔEA`、`LDE<0`；
- 计算结果封存后，才与公开furan `LDE=-39.3 kcal/mol`比较，绝对差不大于`5 kcal/mol`判为定量一致。

若方向判据或定量阈值失败，P11-A判为反对或暂不能判定，不增加分子、基组、泛函或权重方案追逐结论。
