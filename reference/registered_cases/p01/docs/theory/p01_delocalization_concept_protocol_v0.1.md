## 1. 三个必须分开的层级

### 1.1 单轨道表示离域

对固定片段分区`g=1...G`和归一化轨道`phi_i`，定义片段权重`w_ig`，并使用归一化支持熵

`H_i = -sum_g w_ig ln(w_ig) / ln(G)`。

`H_i=0`表示轨道只支持在一个组上，`H_i=1`表示在两个组上等权展开。该量描述单个轨道的表示；占据空间内部酉旋转可以改变它，因此它不是电子态的不变量。

### 1.2 电子密度离域

在正交闭壳层模型中，一阶密度矩阵为

`D = 2 C_occ C_occ^T`。

占据轨道变换`C_occ -> C_occ U`且`U U^T=I`时，`D`严格不变。本项目在固定A/B分区上使用

`L_D(A,B) = ||P_A D P_B||_F`

作为单参考一阶密度相干性的操作诊断。该量在占据空间内部酉旋转下不变，但依赖预先声明的片段分区；它不是相关电子对离域的唯一普遍定义。

在非正交LFMO/AO空间中，生产实现必须改用固定AO度量投影算符，不能直接套用欧氏投影。

### 1.3 能量离域

能量离域必须写成两个明确命名、分别求解的电子态之间的定向差，例如LFMO协议中的`E_FUD-E_DSI`。它是协议定义的状态量，不等于轨道支持熵，也不能仅凭轨道图像推出符号。

## 2. 可证伪数学对照

本协议要求两个对照同时通过：

1. **同一电子态、不同轨道规范：** 将两个完全占据的局域轨道在占据空间内从0°旋转至45°。单轨道支持熵必须从0增至1，但总密度、电子数、分区密度相干性和任意固定一电子算符期望值必须保持不变。
2. **不同电子态：** 比较一个局域双占轨道与一个A/B对称双占轨道。电子数保持2，但密度矩阵、组布居和`L_D(A,B)`必须改变。

如果第一项中密度随轨道规范变化，说明实现错误；如果只依据第一项轨道熵变化就宣称电子离域变化，说明概念混淆。

## 3. 方法映射边界

| 方法 | 轨道表示变化 | 电子态是否必然变化 | 能量离域含义 | 与源LFMO等价性 |
|---|---|---|---|---|
| Canonical MO | 通常呈全分子展开 | 仅占据酉旋转时不变 | 无独立局域态能差 | 否 |
| Boys/Pipek–Mezey占据轨道局域化 | 是 | 纯占据旋转时不变 | 无独立状态能差 | 否 |
| NBO | 是 | 取决于具体删除/微扰协议 | 方法特异 | 否；本阶段尚未执行 |
| BLW | 是 | 在块约束下重优化时改变 | 约束态与全态之差 | 否；本阶段尚未执行 |
| 源定义LFMO DSI/FUD | 是 | 命名态具有状态特异基与密度 | 源定义定向状态能差 | 是，本项目第一期已有范围化重构 |

该表是概念与可观测量映射，不宣称NBO或BLW数值已经复现，也不允许用普通局域轨道替换LFMO。

## 4. 与原著命题的当前关系

公开原著证据在印刷页96明确区分“通过删除Fock元素使分子轨道局域化”和“保证电子局域化”这两个问题。若本协议的酉旋转不变量对照通过，则项目从独立线性代数路径支持这种概念区分。

该完成判据已经满足：乙烯RHF/6-31G(d)的canonical、Boys和Pipek–Mezey占据轨道对照证明轨道片段支持显著变化时AO密度和RHF能量不变；第一期冻结的LFMO DSI-3/FUD证据则提供分别命名、分别求解、具有状态特异密度和定向能量差的受限态对照。由此形成`P01_SCOPED_CONCEPTUAL_DISTINCTION_SUPPORTED`，并把P01标记为范围化完成。

NBO和BLW仅完成概念映射，未作数值执行或LFMO等价性主张；这不影响本命题的逻辑判定，因为P01要求区分可观测量层级，而不要求所有局域化方法给出相同数值。
