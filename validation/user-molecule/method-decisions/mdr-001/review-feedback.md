三项发现需要这样理解：

- **初始占据边界近简并**：支持进一步审查状态选择的敏感性；尚不能证明它是后续失败的唯一原因。
- **占据子空间跳变**：保存记录显示，未经过 DIIS 外推的条件算子迭代也出现跳变，因此只调整 DIIS 参数缺乏充分依据。
- **固定点与能量驻定性**：报告正确地区分了两个问题。但现有端点本身未通过固定点检查，不能把它们当作“已收敛条件态却不满足能量驻定性”的实测反例。

下一步建议让方法责任人与外部计算化学审阅者共同回答四个问题，形成一份可版本化的“方法决定记录”：

| 必须明确的问题 | 应形成的决定 |
|---|---|
| 条件态如何定义？ | 全局闭壳层占据，还是指定片段／子空间占据；哪些约束属于科学协议 |
| 近简并时如何选态？ | 排序、并列处理、状态跟踪及可接受的多解情形 |
| 所报能量如何解释？ | 允许哪些密度或轨道变化；要求驻定性，还是仅作已定义条件态的能量比较 |
| 什么结果算合格？ | 固定点残差、占据映射、能隙等门槛是否与目标条件态相容 |

**尤其要先确认：所要求的条件态是否可能天然不满足现有能隙门槛。** 若定义与门槛冲突，继续更换求解器也无法解决；任何调整都应建立新协议版本，保留旧失败记录。
