**这份材料可以作为专项外审草稿；当前不能宣布 Runtime 全部部署、验收完成。** 我已读取三个审阅入口、相关源码及保存结果，82 项载荷的大小与 SHA-256 全部匹配。本轮仅核验材料和静态审阅，未运行新计算。

V2 的初值公式在给定正定条件下，能够保留普通态占据列空间，并满足屏蔽度量下的电子数和幂等关系。**这些代数性质不保证最终收敛、正能隙或能量解释成立。** 最新三路径诊断各完成一次 F(D0) 求值，随后初始化拒绝、零轨道迭代，尚未测试 V2。

建议在实施前补齐两处具体衔接：

1. **补全种子的求解器准入检查。** V2 文档允许种子电子数误差 ≤`1e-7`，而现有两套残差求解器要求白化投影的迹误差及幂等缺陷均 ≤`1e-10`，生产路径另有密度重构检查。两套检查的度量也不同，因此通过文档检查不一定能进入求解器。应把现有准入检查明确加入 A02，分别记录，保留原门槛。
2. **区分验收项与原项目命题编号。** 包内用户入口的 `P12/P13` 验收项容易与原项目 P12、P13 科学命题混淆，建议加上明确前缀或注释。

外审重点应落在三个问题：

| 问题 | 需要明确的判断 |
|---|---|
| 目标条件态与最终正能隙 | 若目标允许占据边界简并，当前继续拒绝是否符合首版服务范围？ |
| 屏蔽度量与原 AO／网格电子数 | 二者可能不同，拟报告的能量差究竟支持什么用途？ |
| 条件算子与能量导数 | 哪些允许变化能支持驻定性解释，哪些结果仅属于操作性固定点？ |

即使通常的 SCF 已收敛，也仍需区分收敛与稳定性；PySCF 官方文档明确说明，收敛解可能不是局部能量极小值。[PySCF](https://pyscf.org/user/scf.html?utm_source=chatgpt.com)
