# 镜面对称轨道适配与奇偶性分析

分析用户定义镜面下的轨道奇偶性与可行的对称适配。输入包括坐标与镜面位置/法向、AO 标签和基组约定、度量 S、反射的系数表示 R、轨道系数 C 与占据数。可只分析用户给出的 R；若要从几何构造 R，必须具备原子映射、球谐/Cartesian 顺序、局部轴、相位及软件约定，不能仅按 p 轨道名称猜高角动量变换。

检查镜面几何映射、原子元素与基组对应、AO 空间是否反射闭合；检查 $$R^2=I$$、$$R^\dagger S R=S$$。几何不具镜面对称性时只能分析关于指定镜面的奇偶成分，不能称为体系对称本征轨道。缺失表示则给明确待补项或构造代码，不编造 AO 反射矩阵。

检查 C 的 S 正交性与反射后子空间泄漏。先按相同占据数和其他用户约束分块，只在等占据块内作酉旋转以保持密度；占据近似相等需要公开容差与密度变化。对正交且反射闭合的块计算 $$K=C^\dagger S R C$$，验证 Hermitian 性后对角化并构造适配系数；非正交块先做有记录的度量正交化。K 的本征值只有在闭合且对称条件成立时应接近正负1，不能把任意压缩反射谱强行二值化。

分别报告偶/奇/混合或无法判断，计算 $$\|RC'-C'\|_S$$ 和 $$\|RC'+C'\|_S$$、子空间重建与密度残差。相位约定和简并内部排序只是展示选择，不作为物理差异。镜面偶/奇不自动等于普遍的 sigma/pi 成键类型；仅在用户指定平面体系和定义时给相应标注。不得声称完成 NBO、LFMO 或约束 SCF。

可生成复数安全的 NumPy/SciPy 脚本或审查已有输出；无运行能力标记 NOT_EXECUTED。解析例：S=I、R=diag\(1,-1\)、等占据 C=I，分别偶与奇；若子空间只有（1,1）/sqrt\(2\)，反射不闭合且奇偶混合，不能输出严格本征轨道。另测不同占据不能任意混合、错误原子映射和近对称几何。

交付输入与表示约定、对称成立条件、闭合及度量残差、适配结果或不可适配原因、占据与密度保持诊断、执行状态。所有判据公开数值精度及容差，保留原始轨道，不静默对称化；所有公式使用双美元定界，不附带任何私有项目文件。
