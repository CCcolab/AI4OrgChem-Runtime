# 多态与尺寸比较

接收用户定义的体系/尺寸列表、电子态和比较量，或已有运行清单与结果，组织单元登记、依赖计划和结果复核。先区分计划、只读账本、预检和实际执行；Skill不自动生成一套电子态、不启动全批次，也不自带电子结构引擎。对于一般研究按用户明确的协议准备；对于Runtime固定服务使用其真实配置，不能以用户自选体系代替注册对象。

每个单元登记唯一ID、组成与几何、尺寸定义、原子/片段映射、方法/基组/ECP、电荷/自旋、状态/占据、约束、来源和预期结果。明确比较是同体系态差、垂直差、绝热差、尺寸趋势还是按定义归一/加权的组合量。跨组成、电荷、方法或几何的比较须说明参考与守恒关系；未定义的可比性列为缺口。权重、控制态、剔除规则、分母和符号必须来自协议，不凭曲线外观改权重或更换参考。

根据配置建立有向依赖并检查缺父、重复ID、自依赖及循环；先检验当前父结果的资格，再规划子态。匹配源码、协议、profile、镜像、输入与依赖身份以及真实输出哈希；当前合同要求本轮父输出时不能用历史冻结摘要替代。多父态必须列全，读取终端实际生成的输出子目录而非猜运行ID或传顶层输出根。预检通过只说明该阶段的准入，不保证后续SCF或优化收敛。

使用Runtime时读取CURRENT_HIGH_COST_CASES指南、high-cost-cases配置和当前能力表；P11/P12的任务码和Unit是接口标识，展示名称不替换真实参数。使用同一high-cost-cases安装记录，通过run-installed-runtime.py的--task、--mode、--unit、--inputs、--budget、--output-root等实际参数操作；P14独立七任务不能混入此安装家族。历史P11/P12共78个注册态只有两个先导态完成验收的记录须与当前记录核对，登记数量不是验收数量，本Skill创建不新增任何态的PASS。

按已选单元创建新预算，核对单态与全批次CPU/线程、内存、scratch、时间、优化步数及电子调用上限。Runtime的预算文件由真实create-high-cost-budget.py创建，不手写、复用或清空。每个live单元一次，失败保留费用和证据；无自动重试或resume。创建、所属资源探针或清理身份未知时保留预留预算与所属隔离锁，不能以一次查无容器就结算，也不能手动删锁绕过隔离。资源不足列为拒绝，不降低合同内存或科学容差；不因整理账本重跑已验收态。

逐态读取真实结果、方法、电子/优化资格、退出码、调用审计、轨迹和清理回执；合格、失败、拒绝、未执行及未知分列。任何缺失态或门槛失败均不得填成功能量、用插值补科学端点或计为全批通过。先导态的身份与验收只覆盖其实际输入；新安装、新镜像、其他尺寸和其他态不能继承旧资格。

只有完整的协议所需集合、依赖和对称控制均合格后才组装正式比较量。输出每项系数、能量、单位、参考、贡献及闭合残差；如果缺项，最多给有明确标签的部分账本和未闭合清单。相对百分比注明分母及其物理定义，近零分母不报误导百分比；有协方差时保留关联传播。派生组合不是新的独立计算，不把尺寸趋势外推成普适定律，也不把登记CESE等指标误称原著数字的相对误差。

交付单元表、依赖图或依赖表、预算与执行顺序、完整性矩阵、逐态资格、可成立的比较和缺口。无后端时提供可执行计划/真实命令并标NOT_EXECUTED，不安装环境或提交远程作业。新文件用新目录，失败非零退出并保留日志；公式用双美元定界，按平台真实工具保存。轻量验证可用合成三态账本、缺父/循环、重复态、失配身份、未知清理、缺态组装和近零分母；未实际运行不标通过，高成本科学计算须单独登记。
