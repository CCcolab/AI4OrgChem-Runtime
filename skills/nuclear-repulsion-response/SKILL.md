# 核排斥能与几何响应分析

接收分子元素/核电荷、Cartesian 坐标、单位及可选几何序列或位移方向，分析有限非周期体系的核间点电荷库仑能和几何响应。仅坐标即可完成核项数学分析，但不能产生电子能、总能或化学稳定性结论。

确认 Bohr/Angstrom 等坐标单位、原子索引、坐标有限性、重复/碰撞中心、核电荷、同位素、幽灵原子、ECP 与外部点电荷。分子净电荷不改变全电子核电荷；同位素不改变静态核库仑能。ECP 体系按用户软件实际能量定义采用明确电荷，不猜有效电荷；无法确定则输出待确认项。幽灵中心按其真实零核电荷处理。周期、Ewald、均匀背景或特殊嵌入不能直接套有限分子求和，需对应协议。

统一为原子单位，计算 $$E_{nn}=\sum_{A<B}\frac{Z_A Z_B}{R_{AB}}$$，只计算每对一次，列出原子对贡献与最小距离。转换常数注明来源或软件版本。检查碰撞奇点，不能用静默距离截断掩盖非法几何。所有能量和距离列带单位。

若要求 Cartesian 梯度，使用 $$\nabla_A E_{nn}=-\sum_{B\ne A}Z_A Z_B\frac{\mathbf R_A-\mathbf R_B}{R_{AB}^3}$$；力为负梯度，明确符号。验证平移/旋转不变性、总力与力矩残差，并用多步长中心差分交叉检查。用户要求 Hessian 时可用成对解析块或有收敛评估的数值差分，报告误差；曲线方向导数需用户给出坐标路径，路径曲率项不能忽略。核项力不是全分子力，不能用核项极小值预测平衡结构。

几何序列需核对原子映射与单位，分解每对贡献变化，区分拉伸、弯曲和整体刚体运动。没有电子项时明确只给核项响应。可生成可复现 NumPy 程序或核对既有结果；没有执行能力标记 NOT_EXECUTED。

解析例：两个电荷均为1、距离1 Bohr，核排斥能理论为1 Hartree；距离2 Bohr 为0.5 Hartree。刚体平移/旋转保持能量，重合的非零电荷中心须报错。测试还包含 Angstrom 转换、幽灵中心和梯度符号。交付输入约定、原子对账本、核能与响应、验证状态及局限，不把示例当新计算。所有公式用双美元定界，不附带任何私有项目文件。
