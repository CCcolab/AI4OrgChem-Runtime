# 非正交子空间投影与泄漏分析

处理用户提供的重叠/度量矩阵 S、子空间系数 B、待分析向量或系数 C，完成非正交子空间的数学审计。适用于一般线性代数与轨道数据，不从数学投影推断化学能量或电子态认证。

先确认矩阵维度、基组顺序、实数/复数、系数列约定、占据权重、所需泄漏定义及数值精度。缺少 S 时不得默认非正交基为正交；只有用户确认欧氏度量时使用单位矩阵。拒绝非有限数据，检查 S 的 Hermitian 性和正定性。半正定 S 须明确选择有支持的子空间及舍弃阈值，记录降秩对结论的影响；不静默修复负本征值。

使用共轭转置，计算 Gram 矩阵 $$G=B^\dagger S B$$。以 Cholesky/线性求解处理良态满秩数据，避免显式求逆。投影为 $$P=B G^{-1}B^\dagger S$$。秩亏时通过白化后的 SVD 或 Hermitian 特征分解构造带阈值伪逆，列出有效秩、舍弃方向和条件数。P 是系数空间的度量投影，不要求普通欧氏 Hermitian；检查 $$P^2-P$$、$$P^\dagger S-SP$$ 和 $$PB-B$$ 的绝对及相对残差。

对非零向量 c，定义泄漏 $$\ell=\frac{[(I-P)c]^\dagger S[(I-P)c]}{c^\dagger S c}$$；报告它是平方范数比例，非幅值比例。零范数输入标记不可定义。多列输入逐列报告，聚合须注明权重，不能把任意非正交列的简单平均当成密度泄漏。若用户提供 AO 密度矩阵，先确认协变/逆变约定再设计电子数与投影分析，不能混用系数矩阵公式。

根据可用能力选择生成 NumPy/SciPy 脚本、分析已有输出或实际执行；无执行工具就明确 NOT_EXECUTED，不能伪造矩阵、条件数、PASS 或运行日志。代码必须包含输入校验、容差参数、复数支持和可重复输出。示例可用 S=I、B 为第一坐标向量、C 为两个坐标向量，理论泄漏分别为0和1；标记为解析测试，不是用户数据计算。另含近线性相关、复数和错误维度的测试。

交付输入约定、计算方法、秩与条件诊断、各项残差、泄漏结果及局限。容差依尺度、精度和用户用途选择并公开，不套固定项目阈值。区分理论推导、代码未运行、真实运行及验证失败；保存文件时使用当前可用的文档工具，不附带任何项目私有文件。所有公式使用双美元定界。
